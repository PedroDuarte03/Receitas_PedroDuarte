## Branches Criadas

Durante o desenvolvimento do projeto foram criadas várias branches, cada uma destinada a uma funcionalidade específica:

- `feature/bolo-cenoura` – Adição da receita de bolo de cenoura.
- `feature/pao-de-queijo` – Adição da receita de pão de queijo.
- `feature/vegan-recipes` – Criação da página de receitas veganas.
- `feature/receita-colaborativa` – Criação da receita colaborativa.
- `fix/pao-de-queijo-typo` – Correção de um erro de escrita na receita de pão de queijo.

As alterações foram integradas na branch `main` através de Pull Requests.

Durante o desenvolvimento surgiram conflitos, principalmente no ficheiro `index.html`, devido a alterações efetuadas em diferentes branches.

Os conflitos foram resolvidos manualmente, mantendo todas as alterações necessárias e garantindo o correto funcionamento do projeto.

Foi ainda necessário recuperar alguns ficheiros recorrendo ao histórico do Git após um rebase.

## Principais Comandos Git Utilizados

- `git clone` – Clonar o repositório.
- `git branch` – Listar as branches existentes.
- `git checkout` – Mudar de branch.
- `git checkout -b` – Criar uma nova branch.
- `git status` – Verificar o estado do repositório.
- `git add .` – Adicionar alterações à staging area.
- `git commit -m` – Registar alterações no histórico.
- `git push` – Enviar alterações para o GitHub.
- `git pull` – Atualizar o repositório local.
- `git pull --rebase` – Atualizar a branch local mantendo um histórico mais organizado.
- `git log` – Consultar o histórico de commits.
